# Power BI Dashboard Specification

## Page 1 — Executive Cloud Security Posture
KPI cards:
- Total Findings
- Compliance Rate
- Non-Compliant Findings
- High/Critical Findings
- Open Remediation Items
- AWS vs Azure Finding Count

Visuals:
- Compliance by Provider
- Compliance by Control Domain
- Severity Distribution
- Framework Distribution
- Open Risk Trend by Age Band

## Page 2 — Identity & Access
- MFA Coverage / MFA Gaps
- Findings by IAM Owner
- High-Risk IAM Findings
- Provider comparison
- Accepted-risk exceptions

## Page 3 — Network & Data Protection
- Public Exposure Findings
- Encryption Gaps
- Region Distribution
- Severity by Provider
- High/Critical Open Risks

## Page 4 — Remediation & Governance
- Remediation Status
- Aging Bands
- Owner Workload
- Top Risk Score Findings
- Framework mapping (CIS / ISO 27001 / NIST)

## Filters
Provider, Region, Framework, Control Domain, Severity, Owner, Compliance Status, Remediation Status.
