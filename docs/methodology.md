# Methodology

1. Generate synthetic multi-cloud compliance findings.
2. Normalise AWS and Azure findings into one reporting model.
3. Add derived fields for severity, open risk, aging and risk score.
4. Map records to control domains and frameworks.
5. Calculate posture KPIs.
6. Prepare SQL queries and Power BI measures.
7. Define executive, IAM, network/data-protection and remediation views.
8. Document how the model could be adapted to production cloud-security services.

## Risk-score note

The risk score in this portfolio is a simple demonstration model based on severity, non-compliance and aging. It is not presented as a production risk methodology.
